Low Tide Runner — a top-down open-world action game set in the coastal city of San Verano: drive and walk through a living city, dodge traffic, raise your wanted level, and finish five story missions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## How to play

Start a run with **Enter**. Drive through San Verano using the arrow keys or **WASD**, carrying envelopes to their destinations around the city. Each delivery earns money; finish the story by completing the mission sequence.
